A Mappia map is defined by a query: plain JavaScript that lists the layers to show, the tools its users get and the arithmetic that runs over the pixels. Start where your question is:

Build Tools Sliders, pickers, charts, drawing, split views - every tool a map can offer, each with a working example and its picture. See Examples Real maps built with Mappia, opened live - the features used at full scale. Learn Reference How the platform reads a query: evaluation, execution, the layer model, widgets, embedding, pitfalls. Look up API Every property, widget parameter and helper function, generated from the platform source.

Start here

  1. Publish your maps. Upload data and styles from QGIS - the publishing tutorial.
  2. Write your first query. It can be one line - how a query is evaluated.
  3. Add tools. Pick one from Tools, copy its example, then adapt it - the widget markup language explains the rules.
  4. Calculate new maps. Combine published maps pixel by pixel - the execution model.
  5. Embed it. Put the map in your own site and talk to it - embedding a map. Stuck? Pitfalls, and properties that do nothing.
